# AQI App 🌍

A web application to check the Air Quality Index
and understand air pollution levels.

## Features
- Real-time AQI data
- Search by city
- Air quality information
- Responsive design

## Technologies
- HTML
- CSS
- JavaScript
- AQI API

## How to Run
1. Clone this repository.
2. Open the project in VS Code.
3. Run index.html using Live Server.
